# Umstellung auf ver1claude.lovecreative.ch

Die Seite läuft aktuell unter der GitHub-Adresse. Für die eigene Domain
fehlt nur ein DNS-Eintrag bei Infomaniak (nur der Domain-Inhaber kann ihn setzen):

| Feld | Wert |
|------|------|
| Typ | CNAME |
| Name | `ver1claude` |
| Ziel | `taulantfaniqi-hue.github.io.` |

Danach: Datei `CNAME.bereit-fuer-eigene-domain` in `CNAME` umbenennen,
committen, pushen — und in den Pages-Einstellungen die Domain eintragen.
